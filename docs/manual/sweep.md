## How to re-run this

```bash
cd erp
npm run manual:capture                     # starts its own next dev on :3200
MANUAL_BASE_URL=http://localhost:3000 npm run manual:capture   # attach to a running server
MANUAL_USER=someone MANUAL_PASS=… npm run manual:capture       # non-default credentials
MANUAL_OPEN_DRAFT=1 npm run manual:capture # permit opening a template draft (a mutation)
HEADED=1 npm run manual:capture            # watch it drive
```

It reads the database only — it creates no fixtures and deletes nothing. Do not use
`npm run test:e2e` to produce manual screenshots: that harness writes and then reaps its own
dev-DB fixtures, which would rewrite the demonstration dataset these pictures are taken from.
