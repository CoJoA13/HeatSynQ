# Heat-Treat ERP — Build Roadmap

Approved by owner 2026-07-29. One detailed plan per phase, written when the phase starts. Each phase ends in working, testable software. Spec: `docs/superpowers/specs/2026-07-29-heat-treat-erp-design.md`.

| Phase | Contents | Testable outcome |
|---|---|---|
| **1. Foundation** | Next.js + Prisma + PostgreSQL + Docker scaffold; login/users; roles & permissions framework; audit framework; typed settings; app shell (nav + search placeholder); backup script | Log in, manage users/roles/settings |
| **2. Master data** | Customers (addresses/contacts/credit); reference tables (operations+GL, materials, inspection codes/scales, containers, carriers, terms, payment types, salespersons, comments, specs); parts (each-weight, load qty/wt, custom fields, pricing); process masters (step library, revisions); quick-entry grids | Key in real customers/parts/processes |
| **3. Orders & loads** | Order entry (qty+weight required, auto-populate from part, no duplication, autosave); containers; serials `{001-025}`; auto load-split; order board (saved views, traffic light); order hub page; traveler PDF + barcode | Enter and print real work orders |
| **4. Certs & shipping** | Cert records/results/scopes; shipper + MOS + BOL; ship-line-complete; void/reverse; freight; stored PDFs | Cert and ship real orders |
| **5. Invoicing & A/R + QBO** | Pricing resolution; surcharges; invoice runs/grouping; credits; finalize/lock; finance charges; payment batches/applications; statements; aging; month-end close; QBO export | Bill a real month in parallel |
| **6. Quoting** | Quotes; follow-up worklist; quote→order auto-link (pricing tier 1 live) | Quote real work |
| **7. Template designer** | Visual editor; per-customer variants; template versioning; defaults become editable | Owner restyles the traveler/logo |
| **8. Reports & parallel-run tools** | Report set; comparison scoreboard; practice database; first-run wizard; backup polish | Weekly VS-comparison; acceptance month |

Parallel-run capability begins after Phase 5. Acceptance criterion (spec §13): one full closed month agreeing with the books.
